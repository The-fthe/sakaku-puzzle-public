# AGENTS.md

## Agent skills

### Issue tracker

Issues and PRDs are tracked in GitHub Issues for `The-fthe/sakaku-puzzle-public`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the standard five-role triage vocabulary. See `docs/agents/triage-labels.md`.

## Build output layout

- Put every generated player build and build archive under `Builds/`.
- Use `Builds/Windows` for Windows builds and `Builds/Android` for Android builds.
- Use `Builds/WebGL/unityroom_build` for the complete unityroom WebGL build.
- Use `Builds/WebGL/Packages` for unityroom ZIP archives.
