# 効果音

効果音は外部素材のため、このリポジトリには含めていません。ファイルが無い場合は効果音なしで動きます。

| ファイル | 用途 | 入手先 |
| --- | --- | --- |
| `tile-rotate.wav` | タイルの回転 | Unity Asset Store「Ultimate Sound FX Bundle」（Sidearm Studios）の Switch sounds 5 |
| `goal-arrival.wav` | 目的地への到着 | [効果音ラボ](https://soundeffect-lab.info/)「鈴を鳴らす」 |
| `stage-clear.wav` | ステージクリア | [効果音ラボ](https://soundeffect-lab.info/)「琴の滑奏」 |

どの素材も単体での再配布は許されていません。
